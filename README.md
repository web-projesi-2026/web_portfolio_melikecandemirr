**Tech-Timeline**, insanlık tarihinin mekanik hesap makinelerinden modern yapay zeka mimarilerine uzanan teknolojik evrimini dijitalleştiren, interaktif ve dinamik bir web platformudur. Bu proje, teknoloji tutkunlarına geçmişin mekanik hatıralarını, geleceğin dijital kodlarıyla birleştirerek sunar.

## 🎯 Hedef Kitle
* **Akademisyenler & Öğrenciler:** Teknoloji tarihini kronolojik olarak incelemek isteyenler.
* **Yazılım Geliştiriciler:** Dil ve donanım evrimini keşfetmek isteyenler.
* **Dijital Müze Meraklıları:** Teknolojinin dünü ve bugünü arasında bağ kurmak isteyenler.

---

## ⚙️ Temel Özellikler
* **🔐 Gelişmiş Kimlik Doğrulama:** Güvenli üye kayıt, giriş ve profil yönetimi modülleri.
* **🌤️ Canlı İklim Entegrasyonu:** OpenWeatherMap API ile bölge bazlı anlık hava durumu verisi.
* **❤️ Etkileşimli Favori Sistemi:** İçerikleri kaydetme ve profil panelinde yönetme.
* **🌙 Dark/Light Mod:** LocalStorage ile kalıcı tema yönetimi.
* **📱 Responsive Tasarım:** Hamburger menü ile mobilde kusursuz kullanıcı deneyimi.
* **👤 Profil & Kişiselleştirme:** Fotoğraf yükleme ve kullanıcı tercihleri yönetimi.

---

## 🛠️ Kullanılan Teknolojiler
* **Frontend:** HTML5, CSS3, JavaScript (ES6+)
* **Veri Yönetimi:** JSON, LocalStorage (NoSQL tabanlı veritabanı simülasyonu)
* **İletişim Katmanı:** Fetch API, Asenkron (Async/Await) işlemler
* **Versiyon Kontrol:** Git & GitHub
